# StreamVault v2.1 (Realme 9 Pro+ Release)

Complete native Android OTT & personal gallery app optimized for the Realme 9 Pro+ (`arm64-v8a` / Dimensity 920) with custom **N** adaptive launcher icons, Continue Watching hero resume banner, You Can Also Watch series carousel, smooth seeking (`SeekParameters.CLOSEST_SYNC`), Dual Audio & Subtitles, left/right photo swiping, and in-app YouTube/Web link playback.
